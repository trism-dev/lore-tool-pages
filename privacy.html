Privacy Policy

Last updated: 22 October 2026

Lore Channel Tool ("the tool") is a private application used by one person, the owner, to manage their own YouTube channel. It is not offered to the public. This policy explains what Google user data the tool accesses and what it does with it.

Who uses it

Only the owner signs in, with the Google account that owns the channel. No one else can sign in or use the tool.

Google data the tool accesses

Through Google OAuth and the YouTube API Services, the tool requests access to the owner's own YouTube account to:

  • upload videos and custom thumbnails, and set their titles, descriptions, tags, privacy and scheduled publish time;
  • read the channel's own videos and their details;
  • read the channel's YouTube Analytics reports (for example views, watch time, average view duration and traffic sources).

It does not access the owner's email, contacts, files or any other Google service, and it never accesses other people's channels or personal data.

How the data is used

The data is used only to publish the owner's videos and to show the owner how those videos perform, so that future videos can be improved. Analytics figures may be summarized with Google's Gemini API to produce suggestions for the owner; they are not used to train any AI model.

Where it is stored

OAuth tokens, upload records and analytics snapshots are stored only on the owner's own computer. Nothing is stored on a separate server operated for the tool.

Sharing

The tool does not sell, rent or share Google user data with anyone. Data is sent only to Google itself, through Google's APIs, as needed to carry out the uses above.

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google terms

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account › Third-party connections, or through Google security settings. Deleting the tool's local files removes all data it stored.
